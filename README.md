# Library Management System (C++)

## 📌 Description
A console-based Library Management System developed in C++ using object-oriented programming. It allows users to manage books and members efficiently.

## 🚀 Features
- Add Book
- Search Book (by Title or Author)
- Issue Book
- Return Book
- Add Member

## 🛠️ Technologies Used
- C++
- Object-Oriented Programming (Classes & Vectors)
- STL (`vector`)

## ▶️ How to Run
1. Compile: `g++ main.cpp -o library`
2. Run: `./library`

## 📂 Classes Used
- `Book` — stores book ID, title, author, and issue status
- `Member` — stores member ID and name
- `Library` — manages the collection of books and members
